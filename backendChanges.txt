Simple Backend Plan: FastAPI Voice Endpoint

Goal
- Create one simple FastAPI backend server.
- The frontend sends text to one endpoint.
- The backend sends that text to Gemini to generate a response.
- The backend sends Gemini's response text to ElevenLabs.
- The backend returns the generated audio file for the frontend to play.

Backend File
- Put all backend logic in one file:
  - main.py

Required Packages
- fastapi
- uvicorn
- pydantic
- python-dotenv
- google-generativeai
- requests

Environment Variables
- GEMINI_API_KEY
- ELEVENLABS_API_KEY
- ELEVENLABS_VOICE_ID

One Endpoint

POST /chef/voice

Request body:
{
  "text": "recipe:.... why does the sauce look so brown.."
}

Validation:
- text is required
- text must not be empty
- text should have a max length, such as 2000 characters

Response:
- Return MP3 audio bytes directly.
- Content-Type: audio/mpeg
- The frontend can turn the response into a Blob and play it.

Backend Flow
1. Frontend calls POST /voice with text.
2. FastAPI validates the request using a Pydantic model.
3. Backend sends the text to Gemini.
4. Gemini returns a short voice-agent style response.
5. Backend sends Gemini's response text to ElevenLabs.
6. ElevenLabs returns MP3 audio.
7. Backend returns the MP3 audio to the frontend.

Create requirments.txt 
pip install -r requirements.txt

uvicorn main:app --reload

Frontend Usage
- Send a POST request to:
  http://localhost:8000/voice

- Example frontend flow:
  const response = await fetch("http://localhost:8000/chef/voice", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ text: userText }),
  });

  const audioBlob = await response.blob();
  const audioUrl = URL.createObjectURL(audioBlob);
  const audio = new Audio(audioUrl);
  audio.play();
