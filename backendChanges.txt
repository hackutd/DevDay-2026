Simple Backend Plan: FastAPI Voice Endpoint

Goal
- Create one simple FastAPI backend server.
- The frontend sends text to one endpoint.
- The backend sends that text to Gemini to generate a response.
- The backend sends Gemini's response text to ElevenLabs.
- The backend returns the generated audio file for the frontend to play.

Backend File
- Put all backend logic in one file:
  - main.py

Required Packages
- fastapi
- uvicorn
- pydantic
- python-dotenv
- google-genai

Environment Variables
- GEMINI_API_KEY
- ELEVENLABS_API_KEY, add later when audio is turned on
- ELEVENLABS_VOICE_ID, add later when audio is turned on

One Endpoint

GET /health

Response body:
{
  "status": "ok"
}

Use this to check that the backend server is running.

POST /chef/voice

Request body:
{
  "text": "recipe:.... why does the sauce look so brown.."
}

Validation:
- text is required
- text must not be empty
- text should have a max length, such as 2000 characters

Response:
- For first testing, return Gemini's text response as JSON:
  {
    "reply": "Your Gemini response here"
  }
- Later, switch this endpoint back to returning MP3 audio bytes from ElevenLabs.

Backend Flow
1. Frontend calls POST /chef/voice with text.
2. FastAPI validates the request using a Pydantic model.
3. Backend sends the text to Gemini.
4. Gemini returns a short voice-agent style response.
5. Backend returns Gemini's response text as JSON.
6. Later, backend sends Gemini's response text to ElevenLabs.
7. Later, backend returns the MP3 audio to the frontend.

  http://localhost:8000/chef/voice

    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ text: userText }),
  });

  const data = await response.json();
  console.log(data.reply);
